# Produktbilder

Lege hier 6–10 Fotos ab, am besten im Querformat (4:3 oder 3:2), ca. 1600 px breit, als JPG.

Erwartete Dateinamen (Reihenfolge = Anzeige in der Galerie, Bild 1 ist auch das Hero-Bild):

- `zelt-01.jpg` – Außenansicht bei Nacht (Hero)
- `zelt-02.jpg` – Innenraum / Tanzfläche
- `zelt-03.jpg` – Eingang
- `zelt-04.jpg` – LED-Detail
- `zelt-05.jpg` – Party mit Gästen
- `zelt-06.jpg` – Bei Tageslicht
- `zelt-07.jpg` – Gebläse & Taschen
- `zelt-08.jpg` – Soundsystem

Andere Namen, mehr oder weniger Bilder? Einfach die Liste `images` in `../app.js` anpassen.
Solange ein Bild fehlt, zeigt die Seite an seiner Stelle einen Platzhalter mit dem erwarteten Dateinamen.
